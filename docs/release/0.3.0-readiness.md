# 0.3.0 发布就绪记录

## 发布范围

- 单一四级权威文档 `LEVEL.md`。
- 移除根目录分散与旧版 LEVEL 文档。
- 同步 CLI、包契约、安装器、更新器、卸载器、适配器、模板、评测和测试。

## 兼容性

- 项目状态仍支持旧数字语义 `1→1、2→3、3→4` 的迁移。
- 旧 LEVEL 3 重确认为新 LEVEL 2 仍要求批准人和原因。
- 文档入口不再兼容旧文件名；调用方必须改读 `LEVEL.md` 对应章节。

## 发布前验证

发布前必须重新运行并记录：

```text
python -m unittest discover -s tests -v
python scripts/workflow.py doctor --package-root .
python scripts/workflow.py validate-package --package-root .
```

并分别初始化 LEVEL 1–4 临时项目，验证状态、适配器渲染和项目校验。未实际运行的检查不得标为通过。
