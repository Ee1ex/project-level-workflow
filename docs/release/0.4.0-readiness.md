## Risks, rollback, and independent PVS handling

- POSIX staging/rollback 逻辑尚缺本机 Bash 运行证据，发布前宜在 Linux/macOS 或可用 Bash 环境补测。
- PowerShell 安装器依赖可执行的 Python 3.10+；Windows App Execution Alias 可能不可用，测试通过在子进程 PATH 中显式使用已验证 Python 运行时规避该环境问题。
- 安装器先运行包校验，再复制到 PID staging；已有托管目录先移动到 conflict backup，失败时恢复。独立 `project-vibe-spec` 只显示提示，不移动、不覆盖、不卸载。
- 本轮创建的两个冒烟临时根未自动删除，以遵守删除确认约束。
