### Release 正文

ELX Level 2.0 是 Project Level Workflow 1.0 的新品牌版本。它保留个人开发优先的 LEVEL 1–4 模型、双层项目记忆、完整 L2 PVS、L3 复用优先、L4 外部能力路由，以及统一的 GitHub 交付确认边界。

本版本将 Skill 和安装目标切换为 `elx-level`，新项目状态写入 `.elx-level`，项目摘要写入 `docs/elx-level`。`migrate` 可以把旧 `.project-workflow` 一次性复制到新目录，旧目录保持不变；新旧目录并存时停止且不覆盖。公共版本与 workflow 版本为 `2.0`，schema 保持 `2.0`。

本地验证包括 95 项 unittest、Doctor、包校验、LEVEL 1–4 与三平台适配器冒烟、旧状态逐文件 SHA-256 稳定性、PowerShell 安装与失败回滚、README 审计和 Diff 检查。Bash/POSIX 真实运行、用户级平台触发和 GitHub CI 仍待外部验证。
