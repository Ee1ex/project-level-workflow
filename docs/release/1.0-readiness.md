### Release 正文草案

Project Level Workflow 1.0 以 LEVEL 1/2 个人开发为主轨：LEVEL 1 兼顾快速开发与完整项目记忆，LEVEL 2 全量采用包内 PVS 与 Phase 0 → Phase N；LEVEL 3 优先复用已有仓库事实和轻量 Change Record；LEVEL 4 改为先分析、负责人确认后可实施，并只路由外部专业能力。

状态 Schema 升级为 `2.0`，公共版本改为两段式 `1.0`。`0.4.0` 状态可保留 LEVEL 和备份安全迁移；旧 LEVEL 4 保持分析阶段并进入执行确认。所有 LEVEL 的 GitHub 远程交付统一通过 Codex GitHub 插件，在动作前确认并在完成后回读验证。

本地验证包括 80 项 unittest、Doctor、包校验、LEVEL 1–4 与三平台适配器冒烟、`0.4.0` 迁移、只读字节稳定性、PowerShell 安装和失败回滚。Bash/POSIX 运行时及真实用户级平台触发仍待外部验证。
