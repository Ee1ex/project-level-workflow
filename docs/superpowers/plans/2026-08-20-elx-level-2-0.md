# ELX Level 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `Project Level Workflow 1.0` 完整改名并升级为 `ELX Level 2.0`，以安全的一次性复制迁移把旧项目状态转入 `.elx-level`。

**Architecture:** 保持现有 Python 标准库 CLI、四级模型和 schema 2.0 不变，将品牌常量、状态路径和安装目标集中到明确常量。只有 `migrate` 可以从旧状态目录复制迁移；其他只读或日常命令不得暗中迁移。PowerShell、POSIX、Codex、Claude Code、Cursor 和包验证共同引用新标识。

**Tech Stack:** Python 3.10+ 标准库、`unittest`、PowerShell、POSIX shell、Markdown、JSON。

## Global Constraints

- 产品展示名为 `ELX Level`，仓库目标名为 `elx-level`，Skill 标识为 `elx-level`。
- `VERSION = 2.0`、`workflow_version = 2.0`、`schema_version = 2.0`、Git Tag 目标为 `v2.0`。
- 新状态目录为 `.elx-level`，新项目文档目录为 `docs/elx-level`。
- 旧 `.project-workflow` 只允许由 `migrate` 一次性复制；原目录字节保持不变。
- 新旧状态目录并存时停止，不覆盖任何一方。
- 不重新设计 LEVEL 1–4、执行策略或 GitHub Gate。
- 不删除旧安装、旧状态、Tag 或 Release；清理必须另行列出路径和确认。
- 不执行 Push、PR、Merge、仓库改名、Tag 或 Release，直到用户再次明确确认。
- 所有文件编辑使用 `apply_patch`；每个任务遵循失败测试、最小实现、相关测试、Diff 检查、本地提交。

def write_legacy_state(project: Path, level: int = 1) -> Path:
    self_result = run_cli("init", "--project", str(project), "--level", str(level))
    if self_result.returncode != 0:
        raise AssertionError(self_result.stderr)
    current = project / ".elx-level"
    legacy = project / ".project-workflow"
    if current.exists():
        current.rename(legacy)
    return legacy

def test_migrate_copies_legacy_state_without_mutating_source(self):
    with tempfile.TemporaryDirectory() as temp:
        project = Path(temp)
        legacy = write_legacy_state(project)
        before = {p.relative_to(legacy): p.read_bytes() for p in legacy.rglob("*") if p.is_file()}
        result = run_cli("migrate", "--project", temp)
        self.assertEqual(result.returncode, 0, result.stderr)
        current = project / ".elx-level"
        self.assertTrue((current / "state.json").is_file())
        after = {p.relative_to(legacy): p.read_bytes() for p in legacy.rglob("*") if p.is_file()}
        self.assertEqual(after, before)
        state = json.loads((current / "state.json").read_text(encoding="utf-8"))
        self.assertEqual(state["workflow_version"], "2.0")
        self.assertTrue((project / "docs" / "elx-level" / "STATUS.md").is_file())

def test_migrate_stops_when_legacy_and_current_state_both_exist(self):
    with tempfile.TemporaryDirectory() as temp:
        project = Path(temp)
        self.assertEqual(run_cli("init", "--project", temp, "--level", "1").returncode, 0)
        legacy = project / ".project-workflow"
        shutil.copytree(project / ".elx-level", legacy)
        before = (project / ".elx-level" / "state.json").read_bytes()
        result = run_cli("migrate", "--project", temp)
        self.assertEqual(result.returncode, 2)
        self.assertIn("新旧状态目录同时存在", result.stderr)
        self.assertEqual((project / ".elx-level" / "state.json").read_bytes(), before)

- [ ] **Step 4: 实现集中路径和显式迁移**

在 `scripts/workflow.py` 定义：

```python
STATE_DIR_NAME = ".elx-level"
LEGACY_STATE_DIR_NAME = ".project-workflow"
DOCS_DIR_NAME = "elx-level"

def _current_state_paths(project: Path) -> tuple[Path, Path, Path]:
    state_dir = project / STATE_DIR_NAME
    return (
        state_dir / "state.json",
        state_dir / "state.backup.json",
        project / "docs" / DOCS_DIR_NAME / "STATUS.md",
    )

def _copy_legacy_state(project: Path) -> tuple[Path, Path, Path]:
    legacy = project / LEGACY_STATE_DIR_NAME
    current = project / STATE_DIR_NAME
    if legacy.exists() and current.exists():
        raise FileExistsError("新旧状态目录同时存在；请人工核对后保留一份，未覆盖任何状态")
    if legacy.is_dir() and not current.exists():
        legacy_state = _load_json(legacy / "state.json")
        errors = validate_state(legacy_state, project)
        if errors:
            raise ValueError("旧状态无效：" + "；".join(errors))
        shutil.copytree(legacy, current)
    return _current_state_paths(project)
```

约束调用：

- `init`、`validate`、`status`、`transition`、`doctor --project` 和适配器渲染只使用 `_current_state_paths`。
- 如果只有旧目录，除 `migrate` 外的命令返回错误并提示运行 `migrate`，不得自动复制。
- `migrate` 先调用 `_copy_legacy_state`；捕获 `FileExistsError` 返回 `2`，其他验证/复制错误返回 `1`。
- 复制后刷新新副本的 `workflow_version`、写新目录 backup、生成 `docs/elx-level/STATUS.md`；不写旧目录。

把 `references/state-protocol.md` 与 `LEVEL.md` 更新为相同语义。
